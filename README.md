# AI-Memory-Challenge---COMP2S01

An interactive educational game for Grade 5–6 students.

## How to Play

1. Memorize the numbers and their positions.
2. Wait for the numbers to disappear.
3. Answer the question.
4. Use Hint if needed.
5. Progress through three increasingly difficult levels.

## Levels

Level 1 — 4 numbers, 5 seconds
Level 2 — 6 numbers, 4 seconds
Level 3 — 8 numbers, 3 seconds

- HTML
